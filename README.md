# 5000만분의 1

대한민국 어딘가에서 태어난 한 아이가 되어, 실제 통계를 따라 한 생을 끝까지 살아보는 웹 인생 시뮬레이션입니다.

- **태어날 해(1960~2026년)를 고를 수 있습니다.** 인생의 매 해에 그해의 통계가 적용됩니다. 1970년생은 1970년의 영아사망률로 태어나 국민학교에 들어가고, 1988년의 진학률로 학력고사를 보고, 33개월 군 복무를 하고, 1998년 외환위기를 맞습니다. 2026년 이후의 해는 통계청 장래인구추계를 따릅니다.
- 태어날 **지역**은 그해 시도별 출생아 수 비중(1981~2025 인구동향조사, 그 이전은 인구총조사 0~4세 인구), **성별**은 그해 그 시도의 출생성비로 정해집니다. 예를 들어 1990년 대구·경북에서 태어나면 여아 100명당 남아 약 130명 비율로 성별이 뽑힙니다.
- 내 아이의 성별은 낳은 해의 **출산순위별 출생성비**를 따릅니다. 1990년대 초 셋째 이상은 여아 100명당 남아가 200명을 넘었습니다.
- **집안 형편**은 가구 소득 5분위에 따라 무작위로 정해집니다.
- 학원, 고등학교 진로, 수능 이후, 취업 준비, 결혼, 출산, 내 집 마련, 퇴직 후 진로 같은 **갈림길**에서는 직접 고를 수 있습니다. 하지만 결과는 확률을 따릅니다.
- **수명**은 생명표(남 80.6세, 여 86.4세)에 맞춘 사망률 곡선을 쓰고, 소득분위와 건강 상태에 따라 달라집니다.
- 중간중간 **통계 카드**(그해의 출산율·진학률·실업률 등)와 **그해의 일**(올림픽, 외환위기, 월드컵…)이 기록에 남습니다.

### 시대에 따라 달라지는 것

| 항목 | 반영 내용 |
| --- | --- |
| 수명 | 해마다 그해 기대수명(생명표, 이후 추계)에 맞춰 사망률을 다시 보정 |
| 학교 | 중학교·고등학교 진학률(1970년대에는 진학 못 하는 아이가 많았음), 국민학교→초등학교(1996), 과외 금지(1980~2000), 예비고사→학력고사→수능 |
| 대학 | 고졸자 대학진학률(1990년 33% → 2008년 84% → 지금 73%) |
| 군대 | 입대 연도별 복무기간 36→33→30→26→24→21→18개월, 방위병·공익·사회복무요원 |
| 일 | 농업 비중(1970년 50%), 이농, 그해 실업률에 비례하는 해고·구직, 외환위기 구조조정, 1998년 이전 비정규직 비중 |
| 결혼·출산 | 그해 평균 초혼 연령과 평생 혼인 비율, 시대별 출산 경향, 여성의 결혼·출산 퇴직(경력단절) |
| 돈 | 2024년 가치 기준. 그해 실질임금 지수와 소득 대비 집값(PIR) 흐름으로 조정 |
| 연금 | 국민연금은 1988년부터(자영업·농어민 1995년) 가입한 해만큼, 기초연금 2008·2014년 도입 |
| 이름 | 태어난 시대에 흔했던 이름 |

기술: Next.js 16 (App Router) · React 19 · TypeScript · 정적 사이트로 내보내기(`output: 'export'`)

## 시작하기

Node.js 20.9 이상이 필요합니다.

```bash
npm install
npm run dev        # http://localhost:3000
```

| 명령 | 하는 일 |
| --- | --- |
| `npm run dev` | 개발 서버 (코드를 고치면 바로 반영) |
| `npm run build` | 정적 사이트를 `out/` 폴더로 빌드 |
| `npm start` | 빌드된 `out/` 폴더를 로컬에서 띄워 보기 |
| `npm run typecheck` | 타입 검사 |
| `npm run simulate` | 지금 태어난 1만 명을 자동으로 살려서 통계와 비교 |
| `npx tsx scripts/simulate.ts 1975` | 1975년생 1만 명으로 검증 |
| `npx tsx scripts/simulate.ts all` | 1960~2026년생을 10년 단위로 한 번에 검증 |

게임 조작: `Space` 일시정지 · `→` 바로 다음 해 · `1`~`3` 선택지 고르기 · 상단·첫 화면에서 1년의 길이(1·2·4·7·12초) 선택, 진행 막대로 다음 해까지 남은 시간 표시

## 폴더 구조

```
src/
  app/
    layout.tsx        HTML 뼈대, 페이지 제목·설명

    globals.css       디자인 전체
    icon.svg          파비콘
  components/
    Game.tsx          게임 상태와 진행 타이머 (시작 → 진행 → 마지막 화면)
    Intro.tsx         시작 화면, 지난 생 목록
    Hud.tsx           상단 이름·나이·수치·진행 막대·1년 길이 선택
    LifeLog.tsx       연도별 생애 기록
    ChoicePanel.tsx   아래에서 올라오는 선택지
    Ending.tsx        마지막 화면, 결과 복사
  lib/
    data.ts           2024년 기준 통계와 출처 (직업 연봉, 지역별 집값 등)
    timeline.ts       연도별 통계와 출처 (출생·사망·진학·결혼·실업률·임금·집값·제도·그해의 일)
    births.ts         시도별 출생아 수, 출생성비(전국·시도·출산순위별) KOSIS 원자료
    names.ts          시대별 흔한 이름
    engine.ts         시뮬레이션 엔진 (React 없음, Node에서도 실행됨)
    content.ts        사건 문장, 직업 이름, 장래희망 (시대 제한 포함. 문장을 늘리려면 여기)
    text.ts           조사 붙이기(을/를, 이/가…), 금액 표시
    random.ts         시드 고정 난수
    storage.ts        브라우저 저장 (설정, 지난 생)
scripts/
  simulate.ts         통계 검증 도구
```

## 통계 검증

`src/lib/timeline.ts`, `data.ts`, `engine.ts`를 고친 뒤에는 꼭 돌려 보세요.

```bash
npx tsx scripts/simulate.ts all
```

현재 결과 (코호트별 5천 명, 모든 선택은 자동):

| 태어난 해 | 대학 진학(고졸자 중) | 실제 | 첫 결혼 나이 중앙값 남/여 | 실제 평균 초혼 | 50세까지 결혼 남/여 | 45세 여성 자녀 수 | 50세 자가 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1960 | 28% | 27% | 28 / 23세 | 27.8 / 24.4세 | 98 / 99% | 1.94명 | 39% |
| 1970 | 34% | 34% | 29 / 25세 | 29.3 / 26.2세 | 87 / 95% | 1.64명 | 57% |
| 1980 | 59% | 66% | 32 / 28세 | 31.8 / 28.4세 | 81 / 90% | 1.35명 | 57% |
| 1990 | 79% | 81% | 33 / 30세 | 33.2 / 30.4세 | 79 / 86% | 1.10명 | 58% |
| 2000 | 73% | 72% | 34 / 32세 | 34.3 / 31.8세 | 75 / 84% | 1.02명 | 61% |
| 2026 | 73% | 73% | 34 / 32세 | 34.6 / 32.3세 | 76 / 83% | 1.00명 | 64% |

중학교·고등학교 진학률, 기대수명도 함께 출력됩니다. 기대수명은 '출생 연도의 기간 기대수명'보다 실제 평균 수명이 길게 나오는데, 그 뒤로 사망률이 계속 낮아진 것을 해마다 반영하기 때문입니다.

**알려진 한계**
- 1960년대생의 50세 자가 보유율(39%)이 실제 50대 가구(약 70%)보다 낮습니다. 저학력·농업·외벌이 비중이 큰 세대의 저축 모형이 단순하기 때문입니다.
- 1980년생의 대학 진학률이 실제보다 7%p 낮습니다(진학률이 가장 가파르게 오르던 시기).
- 실질임금·집값 지수, 1970년 이전 수치, 1981년 이전 시도별 출생 분포(인구총조사 0~4세로 대신)와 광역시 분리 전 해의 시·도 나눔, 1985~1989년 시도별 출생성비, 결혼·출산 경향 배수는 공표치로 만든 **추정·보정값**입니다. `timeline.ts` 주석에 (공식)/(추정)/(추계)로 표시해 두었습니다.

## 데이터 검증 체크리스트 (공개 전에 꼭)

`src/lib/data.ts`의 숫자는 **공개 통계를 바탕으로 한 근사치이고, 일부는 기억에 의존해 채웠습니다.** 공개 전에 [KOSIS 국가통계포털](https://kosis.kr)에서 아래 항목을 최신 값으로 확인해 교체하세요.

- [x] 시도별 출생아 수 1981~2025 — 인구동향조사 (KOSIS DT_1B8000G), 1960~1980은 인구총조사 0~4세 인구 (DT_1IN0001)
- [x] 합계출산율·출생성비 1970~2025 (DT_1B8000F), 출산순위별 출생성비 1981~2025 (DT_1B80A01), 시도별 출생성비 1990~2025 (DT_1B81A19)
- [ ] 소득 5분위별 월평균 소득 — 가계동향조사
- [ ] 소득 5분위별 순자산 — 가계금융복지조사
- [ ] 기대수명(남·여) — 생명표 (값을 바꾸면 사망률 계수 `a`를 다시 맞춰야 함)
- [ ] 소득분위별 기대수명 격차 — 국민건강보험공단 연구
- [ ] 연령대별 사망원인 비중 — 사망원인통계
- [ ] 사교육 참여율·비용 — 초중고 사교육비조사
- [ ] 대학진학률 — 교육기본통계
- [ ] 기업 규모별 월평균 소득 — 일자리행정통계 임금근로일자리 소득
- [ ] 비정규직 비중, 청년 고용률 — 경제활동인구조사 (부가조사)
- [ ] 평균 초혼 연령, 50세 미혼율 — 혼인통계, 인구주택총조사
- [ ] 주택 소유 가구 비율 — 주택소유통계
- [ ] 지역별 주택 평균가 — 한국부동산원
- [ ] 국민연금 평균 수령액 — 국민연금공단 통계
- [ ] 노인 상대빈곤율 — 가계금융복지조사
- [ ] **연도별 계열(`timeline.ts`)**: 출생아 수·합계출산율(인구동향), 기대수명(생명표), 영아사망률, 중·고·대 진학률(교육통계연보), 평균 초혼 연령(혼인통계), 혼인상태생명표, 실업률(경제활동인구조사), 농림어업 취업자 비중, 실질임금(사업체노동력조사), PIR(KB부동산), 장래인구추계(2022~2072)
- [ ] 군 복무기간 30개월 시작 연도(지금은 1984년으로 추정)

## 설계 원칙

- 금액은 모두 **2024년 현재 가치(만원)** 로 계산합니다. 물가 상승은 빼고, 실질 상승분만 반영합니다.
- 같은 무작위 사건은 한 생에 한 번만 나옵니다.
- **자살은 사망 원인에서 제외**하고 나머지 원인에 비율대로 나눴습니다. 시작 화면에 자살예방상담전화 109를 안내합니다.
- 점수나 순위는 없습니다. 마지막 화면은 "같은 해 태어난 아이 중 몇 %가 나보다 오래 사는지"만 보여 줍니다.
- 서버가 필요 없습니다. 기록은 브라우저에만 저장됩니다.

## 배포

`npm run build`로 만든 `out/` 폴더가 그대로 정적 사이트입니다.

- **Cloudflare Pages**: 저장소 연결 → 빌드 명령 `npm run build`, 출력 디렉터리 `out`
- **Vercel**: 저장소를 가져오면 자동으로 인식
- **GitHub Pages**: `out/` 폴더를 올리기 (하위 경로에 올릴 땐 `next.config.ts`에 `basePath` 추가)
