# 현실성 규칙

## 문제

사건에 `from`(달력 연도)만 붙어 있으면, 2012년 이후 '복지관에서 스마트폰 쓰는 법을 배웠다'가
1995년생에게 2070년에 나온다. 1995년생은 스마트폰을 10대에 쓴 세대다.

## 규칙

1. **기술 처음 배우기**는 그 기술이 나왔을 때 이미 어른이었던 세대만.
   - 사건에 `bornFrom`/`bornTo`(출생연도)를 붙인다. 엔진 `eventFits` 가 검사한다.
   - 스마트폰 배우기 1955년생까지, 키오스크 헤매기 1962년생까지. 부모님께 스마트폰 알려 드리기 1985년생까지·2035년까지(그 뒤는 '부모님이 휴대폰 설정을 바꿔 달라며 전화').
2. **'처음' 사건**(처음 스마트폰, 처음 컴퓨터)은 그 기술이 퍼진 해와 그때 나이가 맞을 때만.
3. **미래(2027년 이후)** 문장은 지금 기술의 이름을 피한다. 일반적인 말로 쓰거나 `to` 를 붙인다.
   - 예: '단체 대화방'은 괜찮다. 'PC통신', '삐삐', '비디오 가게'는 반드시 `to`.
4. **나이 범위**: 노년 사건은 `ages` 를 붙인다. 손주·은퇴·연금은 형편 조건(`when`)으로.
5. **비정규 일의 은퇴**는 '오래 다닌 직장'이 아니라 '오래 해 온 ○○ 일'로.
6. **제도·이름**: 국민학교→초등학교(1996), 만 나이 통일(2023)처럼 바뀐 이름은 `timeline.ts` 의 함수로.

## 검사

`scripts/test.ts` 의 시대 검사가 아래를 확인한다. 새 규칙을 만들면 여기와 테스트에 함께 추가한다.

| 문장 조각 | 조건 |
|-----------|------|
| `스마트폰 쓰는 법`, `키오스크 앞에서` | 출생연도 ≤ 1965 |
| `부모님께 스마트폰` | 출생연도 ≤ 1995, 연도 ≤ 2035 (그 뒤 부모는 디지털 세대) |
| `이혼했다` | 90세 미만 (엔진은 55세부터 이혼 확률을 줄여 75~84세 5%, 85세부터 0) |
| `삐삐` | 1993 ≤ 연도 ≤ 1999 |
| `PC통신` | 1990 ≤ 연도 ≤ 2002 |
| `비디오 가게` | 연도 ≤ 2005 |
| `처음으로 스마트폰` | 2009 ≤ 연도 |
