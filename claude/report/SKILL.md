# 결과 리포트

## 들어갈 것

1. **머리**: 이름, 생몰년, 나이, 태어난 곳. 한 줄 묘비명(성향·관심으로 만든 문장).
2. **생애 그래프**: 나이별 순자산(선)과 행복·건강(얇은 선). 결혼·첫 아이·집·은퇴 같은 사건을 점으로.
3. **이런 사람이었다**: 성향 4축 막대(도전↔안정 …), 가장 큰 관심 분야.
4. **인생의 갈림길**: 직접 고른 큰 선택 5~8개(나이 · 선택).
5. **또래와 비교**: 같은 해 태어난 사람 중 나보다 오래 산 비율, 학력·결혼·자녀·자가·순자산이 또래 분포에서 어디쯤인지.
6. **숫자로 본 생**: 지금의 6칸(학력·일·가족·재산·떠난 이유) 유지.
7. **버튼**: 다시 태어나기 / 다른 해 / 결과 복사 / 생애 기록 다시 보기.

## 데이터

- `life.history` (해마다 YearResult) 로 그래프를 만든다. `summary()` 에 `series`(나이별 순자산·행복·건강)와
  `turningPoints`(직접 고른 갈림길), `traits`, `interest` 를 더한다.
- 또래 비교 기준은 `timeline.ts`·`data.ts` 의 공식 통계로만 (시뮬레이션 값이 아닌).

## 차트 규칙

- 차트는 손으로 그린 SVG. dataviz 스킬의 규칙(축·색·접근성)을 따른다.
- 색은 globals.css 토큰(--blue, --accent, --good)만.

## 구현

- `engine.summary()` 에 `series`(나이별 순자산·행복·건강, 같은 나이의 마지막 결과), `moments`(첫 일·결혼·첫 아이·내 집·은퇴,
  milestone 문장에서 찾는다), `cohort`(수명·학력·결혼·자녀를 그 세대 공식 통계와), `turningPoints`(운에 맡긴 것 제외).
- `LifeChart.tsx`: 한 축 SVG 선 그래프. 실제 폭을 재서 그린다(글자가 늘어나지 않게). 세로 기준선 + 툴팁(모든 선의 값),
  ←/→ 키로도 움직인다. 사건 이름표는 가까우면 한 줄씩 비키고 세 줄을 넘으면 점만.
- 색: 순자산·행복 `#2a78d6`, 건강 `#eb6834` — dataviz `validate_palette.js` 흰 카드 기준 다섯 검사 모두 통과.
  (사이트의 --blue `#2e4a6b` 는 너무 어둡고 채도가 낮아 범주 색 검사에서 떨어졌다.) 다크 모드는 사이트에 없다.
- `TraitBars.tsx` 는 사이드 패널과 리포트가 함께 쓴다. `epitaph()` 가 성향 상위 둘과 관심 분야로 한 줄을 만든다.
- 표로 보기(5년마다)를 둔다: 색을 못 읽거나 마우스를 쓰지 않는 사람도 값을 볼 수 있게.
