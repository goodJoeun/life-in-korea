# 성향과 갈림길

## 목표

지금은 결과가 대부분 확률로 정해지고, 플레이어의 선택이 방향을 만들지 못한다.
선택이 쌓여 '이런 사람'이 되고, 그 사람에게 맞는 선택지가 나오게 한다. 결과는 여전히 확률을 따른다.

## 데이터

```ts
life.traits    // 성향 축 -100~100 (0에서 시작)
  bold      도전 ↔ 안정
  social    어울림 ↔ 혼자
  diligent  성실 ↔ 자유
  thrift    절약 ↔ 씀씀이
life.interests // 관심 분야 점수 0~ (쌓이기만 한다)
  science 과학·수학 · words 글·말 · art 예술 · sport 운동 · tech 컴퓨터 · care 사람 돌보기 · biz 장사·돈 · nature 자연·농사
```

- `life.mainInterest()` = 가장 높은 관심 분야 (5점 이상일 때).
- `life.trait(k)` 로 읽고, 갈림길의 `shape` 로만 바꾼다(한 번에 ±10~25).

## 갈림길 (`src/lib/paths.ts`)

```ts
interface PathChoice {
  id: string;              // 한 생에 한 번
  ages: [number, number];  // 이 나이 사이에서
  chance?: number;         // 조건이 맞는 해에 나올 확률 (기본 0.5)
  from?, to?, born?        // 시대 조건 (realism SKILL)
  when?: (l) => boolean    // 형편 조건 (관심 분야, 성향, 학력, 직업…)
  prompt: string | (l) => string
  options: (l) => PathOption[]   // 형편에 따라 선택지가 달라진다
}
interface PathOption {
  label, desc, auto            // auto: 운에 맡길 때 가중치. 성향에 맞는 쪽이 높아진다
  shape?: { traits?, interests? }  // 고르면 성향·관심이 바뀐다
  outcomes: [가중치, 문장, Effect][] // 결과는 확률
  then?: (l) => void           // 엔진 상태를 바꾸는 후속 처리 (직업 바꾸기, 플래그 등)
}
```

엔진 `pathChoice()` 는 해마다 다른 갈림길이 없을 때:
1. `chance: 1` 인 것(8세 흥미, 문·이과, 전공)이 있으면 그것.
2. 없으면 `chance ≥ 0.6` 인 것(방과 후, 동아리, 진로 상담…)을 자기 확률로 굴린다.
3. 그래도 없으면 45% 확률로 후보 중 하나를 chance 가중치로 뽑고 다시 chance×1.6 으로 굴린다.

운에 맡기기 가중치 = `auto × exp(lean · 성향/40 또는 관심/6)` (±1.5에서 자름). 그래서 성향이 쌓일수록 그 방향을 더 자주 고른다.

직업 이름: `startJob` 이 관심 분야가 있으면 65% 확률로 `INTEREST_TITLES[관심][직업 종류]` 에서 고른다(학위가 필요한 이름은 4년제 이상).
은퇴: `retire-plan` 에서 고른 것(save·work·farm)에 따라 `mainRetire` 선택지가 달라진다.

측정 (운에 맡기기 1,000명): 한 생 선택 평균 27번(갈림길 10.3, 기본 9.9, 작은 갈림길 6.8). 예전 20.5번.
8세 흥미 97% · 방과 후 90% · 동아리 87% · 노년 취미 88% · 진로 상담 45% · 창업 5% · 대학원 3%.

## 통계 보정

- 갈림길의 수치 효과는 작게 (±1~4). 학창 시절 `ability` 는 0.5배로 반영된다(진학률 보정).
- 직업 종류의 분포는 그대로 두고 **직업 제목**만 관심 분야에 맞춘다. 창업·이직처럼 종류가 바뀌는 선택은 확률을 낮게.
- 고친 뒤 `simulate.ts all` 로 진학률·30세 직업 분포가 크게 변하지 않았는지 본다.
