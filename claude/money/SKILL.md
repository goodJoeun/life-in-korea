# 돈 관리

## 목표

플레이어가 독립한 뒤 **씀씀이**와 **모은 돈을 어디에 둘지**를 직접 정한다. 결과는 그 시대의 실제 수익률(과거)과
확률(미래)을 따른다. '운에 맡기기'는 그 시대 사람들이 흔히 하던 방식(대부분 예금)을 쓴다.

## 상태 (엔진)

```ts
life.plan = {
  spend: 'frugal' | 'normal' | 'loose',   // 소비: 가처분소득의 60% / 70% / 80%
  alloc: { deposit, stock, global, crypto } // 합 100 (%)
}
life.cash      // 예금(현금). 빚이면 음수
life.invest    // { stock, global, crypto } 평가액 (만원, 2024년 가치)
```

- 해마다 `economy()` 에서: 소득 − 지출 = 남는 돈 → `alloc` 비율대로 넣는다. 남는 돈이 음수면 예금에서 뺀다.
- 그다음 자산별 실질 수익률을 곱한다. 비율이 바뀌면 다음 해부터 새로 넣는 돈에만 적용(이미 산 것은 그대로),
  '모두 예금으로' 같은 정리 버튼은 따로.
- 빚(cash < 0)이 있으면 투자에 넣지 않는다.
- 순자산 = 예금 + 투자 평가액 + 집값 − 주택대출.

## 수익률 (`src/lib/timeline.ts`)

- `DEPOSIT_REAL` 예금 실질금리 (예전 엔진 1.03/1.01 을 그대로 잇는다).
- `KOSPI_REAL[연도]` 국내 주식 실질 수익률 (연말 지수 근사 − 물가, 추정). 1980년 이전은 없음(투자 불가).
- `GLOBAL_REAL[연도]` 해외 주식(미국 지수) 원화 실질 수익률 근사 (2000년부터 쉽게 살 수 있었다고 본다).
- `CRYPTO_REAL[연도]` 코인 (2017년부터). 변동이 매우 크다.
- 미래(자료가 없는 해): 평균·변동성으로 무작위 (주식 실질 4%/18%, 해외 5%/16%, 코인 5%/70%).
- 개인 차이: 과거 해에도 종목 차이만큼 ±(주식 8%, 코인 30%) 흔들림을 더한다.

## 화면

- 사이드 패널 '자산' 카드에 '돈 관리' 버튼 → 패널: 씀씀이 3단계, 배분 슬라이더 4개(합 100%), 자산별 평가액.
- 독립 전에는 잠겨 있다.
- 바꾸면 `Game` 이 `life.setPlan(plan)` 을 부르고 동작 기록에 `{ p: plan }` 을 남긴다(되살리기).

## 갈림길과 사건 (paths 와 연결)

- 1999 벤처 열풍, 2007 펀드 열풍, 2017·2021 코인, 2020 동학개미 같은 해에 '투자할까' 갈림길.
- 성향 `thrift`(절약)·`bold`(도전)가 운에 맡길 때의 기본 계획과 갈림길 가중치를 바꾼다.

## 통계 보정

- 기본 계획(운에 맡기기)의 60세 순자산 중앙값이 예전 엔진과 크게 다르지 않아야 한다 (`simulate.ts all`).
