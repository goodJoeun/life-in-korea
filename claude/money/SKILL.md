# 돈 관리

## 목표

플레이어가 독립한 뒤 **씀씀이**와 **모은 돈을 어디에 둘지**를 직접 정한다. 결과는 그 시대의 실제 수익률(과거)과
확률(미래)을 따른다. '운에 맡기기'는 그 시대 사람들이 흔히 하던 방식(대부분 예금)을 쓴다.

## 상태 (엔진)

```ts
life.plan = { spend: 'frugal' | 'normal' | 'loose', alloc: { deposit, stock, global, crypto } } // 합 100 (%)
life.cash    // 쓸 수 있는 돈 '전체'(예금 + 투자). 빚이면 음수. 예전 코드가 모두 이것을 본다
life.invest  // { stock, global, crypto } — cash 가운데 투자에 들어 있는 몫
```

- `cash` 를 전체 유동 자산으로 둔 덕에 집 계약금·갈림길 비용 같은 예전 로직은 그대로 돈다. 쓴 돈은 예금 몫에서 먼저 빠지고,
  다음 정산에서 다시 나눈다. 화면에는 `holdings()` 가 예금 = cash − 투자 로 보여 준다.
- 해마다 `economy()` 끝의 `grow()`: 계획대로 **다시 나누고(리밸런싱)** → 예금에 `depositRate`, 투자에 그해 수익률 + 종목 차이.
  빚(cash ≤ 0)이면 투자는 0, 빚 이자 4%.
- 소비: 가처분소득 × `SPEND_RATE` (0.6/0.7/0.8). 아껴 쓰면 행복 −0.6, 넉넉히 쓰면 +0.6 (해마다).
- `setPlan(plan)` 은 화면·되살리기 동작(`{ p: plan }`), `tiltPlan`·`safePlan`·`setSpend` 는 갈림길용.
- 크게 오르내린 해(−25% 이하, +35% 이상, 들고 있는 돈이 300만 원 넘을 때)는 기록에 남긴다.

## 수익률 (`src/lib/timeline.ts`)

- `depositRate(year)` 예금 실질금리 (예전 엔진 1.03/1.01 을 그대로 잇는다).
- `investReturn(kind, year)`: 연말 값으로 계산한 실질 수익률.
  - 국내 주식: 코스피 연말 지수(1980~2025, 추정) + 배당 1.5% − 물가. 1981년부터 고를 수 있다.
  - 해외 주식: S&P 500 배당 포함 수익률 × 원·달러 환율 변화 − 물가. 2000년부터.
  - 코인: 비트코인 달러 가격 × 환율 − 물가. 2018년부터 (2017년 말 열풍 이후).
  - 물가: 소비자물가 상승률 연간값(2025 추정).
- 미래(자료가 없는 해): 평균·변동성으로 무작위 (`INVEST_FUTURE`: 주식 실질 4%/18%, 해외 5%/16%, 코인 3%/60%).
- 개인 차이: 과거 해에도 종목 차이만큼 ±(`INVEST_NOISE`: 주식 8%, 해외 3%, 코인 25%) 흔들림을 더한다.

## 화면

- `MoneyPanel` (사이드 패널 '자산' 카드): 예금·국내 주식·해외 주식·코인 잔액과 지난해 수익률.
  '돈 관리'를 누르면 씀씀이 3단계와 배분 슬라이더(10% 단위). 초안만 바꾸고 '적용'을 눌러야 반영된다.
- 독립 전에는 자산 카드 자체가 없다. 아직 살 수 없는 투자는 슬라이더가 꺼져 있다.
- 적용하면 `Game.changePlan` 이 `life.setPlan` 을 부르고 동작 기록에 `{ p: plan }` 을 남긴다(되살리기).

## 갈림길과 사건 (paths 와 연결)

- paths.ts: 벤처 열풍(1999~2000), 펀드 열풍(2006~07), 동학개미(2020~21), 코인(2021), 지수 펀드(2027~),
  노년 안전 자산(60~80세, 투자 30% 이상), 씀씀이(26~40세).
- 겹치던 '모아 둔 돈을 어디에 넣을까?' 갈림길과 '주식으로 손해/수익' 사건은 뺐다(실제 수익률과 어긋나므로).

## 통계 보정

- 기본 계획(운에 맡기기)의 60세 순자산 중앙값이 예전 엔진과 크게 다르지 않아야 한다 (`simulate.ts all`).
- 측정: 1960년생 1.23억→1.40억(+13%), 1970년생 2.58억→2.98억(+16%), 2010년생 7.27억→7.47억(+3%).
  차이는 열풍 갈림길에서 주식을 산 사람들의 실제 수익(예금보다 높았다). 씀씀이 가중치는 평균 0.7이 되게 대칭.
